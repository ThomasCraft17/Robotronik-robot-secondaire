# Robotronik-robot-secondaire

La carte utiliser est une ESP-32s V1.1.

## Electronique

L'ESP-32s est allimenter par une batterie portable qui sera fixer sur le robot.

## Programme

Le code sera fait en python pour le rendre plus accessible et rapide à faire.

## Principe

Une manette est connecté en bluetooth à une manette qui permet de contrôler le robot.
