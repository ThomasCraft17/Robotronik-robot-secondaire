# Robotronik-robot-secondaire

La carte utiliser est une Rasberry Pi 5

## Electronique

Il nous manque le shield pour alimenter la carte. On code juste les inputs et on verra les outputs une fois qu'on a la shield

## Programme

Le code sera fait en python pour le rendre plus accessible et rapide à faire.

## Principe

On veut pouvoir host un site web sur la carte qui permettra de contrôler le robot soit avec un clavier soit avec une manette. ZQSD dans le cas d'un clavier et gâchette plus joystick avec la manette.
